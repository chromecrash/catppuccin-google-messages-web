A soothing pastel userstyle for <a href="https://messages.google.com/web">Google Messages for web</a>.
</p>

> This is an unofficial userstyle and is not made or maintained by the Catppuccin team.
> It's my first userstyle, so it may not meet their standards. I'm not planning to submit
> it to the official collection, but anyone who wants to is welcome to, as long as they credit me.

## Install

1. Install [Stylus](https://add0n.com/stylus.html) for your browser.
2. [Click here to install the style](https://github.com/chromecrash/catppuccin-google-messages-web/raw/refs/heads/main/catppuccin.user.less).
3. Open the style's settings in Stylus to choose your flavors and accent.
